# `Space Cheese`

Ein Retro-Arcade-Shooter mit Käse-Thema: Eine ausserirdische Käseflotte greift die Galaxie an. Du steuerst den letzten einsatzfähigen Raum-Käsehobel und musst die Invasion aufhalten. Das Hauptmenü ist ein Arcade-Automat, den du zuerst einschaltest.

**[Herunterladen (neueste Version)](https://github.com/kaesehobel79ch/space-cheese/releases/latest)**

Kostenlos (Freeware) von Käse_Hobel.

## Installieren

1. Unter „Herunterladen“ die Datei `Space-Cheese-<Version>.zip` laden.
2. ZIP entpacken.
3. `SpaceCheese_<Version>_Setup.exe` starten und den Schritten folgen.

## Voraussetzungen

- Windows 10 oder Windows 11 (64 Bit)
- Internet nur für die Suche nach Updates; ohne Internet läuft das Spiel normal.

Setup und Programm sind mit dem eigenen Zertifikat von Käse_Hobel signiert, nicht mit einem Zertifikat, das Windows kennt. Beim ersten Start kann sich deshalb der Windows-Schutz SmartScreen oder ein Virenscanner melden. Das ist ein Fehlalarm.

## Datenschutz

Beim Start fragt das Spiel eine kleine Versionsdatei beim Speicherdienst Cloudflare R2 ab. Dabei wird wie bei jedem Abruf einer Internetseite die Internetadresse des Rechners übermittelt, sonst nichts: keine Kennung, kein Name, keine Spielstände. Ein Update wird nur nach ausdrücklicher Bestätigung geladen und installiert.

## Echtheit prüfen

Zu jedem Download gehören eine Prüfsumme (`.sha256`) und eine Unterschrift (`.asc`) mit dem Schlüssel von Käse_Hobel.
